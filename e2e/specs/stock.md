# Stock E2E 테스트 계획

## 개요
- 대상 페이지: /stocks, /stocks/trades, /stocks/[stockId], /stocks/accounts/[accountId]
- 주요 기능:
  - 포트폴리오 요약 카드 (총 평가금액, 총 투자금액, 미실현 손익, 실현 손익)
  - 계좌 셀렉터 드롭다운 및 계좌 필터링
  - 보유 종목 테이블 (손익 색상 표시, 종목 상세 링크)
  - 계좌 등록 다이얼로그
  - 매매 내역 CRUD (추가 / 수정 / 삭제)
  - 매매 내역 필터 (종목, 계좌, 유형, 날짜) 및 페이지네이션
  - 종목 상세 — 종목 정보 헤더, 보유 현황, 매매 내역
  - 계좌 상세 — 계좌 정보, 보유 종목, 월별 실현 손익 차트 (연도 네비게이션)

---

## 테스트 시나리오

### 1. /stocks — 포트폴리오 개요

#### 1-1. 요약 카드 4개 렌더링
- **전제조건**: 로그인된 상태, /stocks 접근
- **단계**:
  1. /stocks 페이지 로드
  2. 카드 제목 텍스트 확인
- **기대 결과**:
  - "총 평가금액", "총 투자금액", "미실현 손익", "실현 손익" 카드가 모두 표시됨
  - 각 카드에 숫자값이 로딩 후 렌더링됨 (로딩 중일 때는 "-" 표시)

#### 1-2. 계좌 셀렉터 — 전체 계좌 기본 선택
- **전제조건**: 로그인된 상태, /stocks 접근
- **단계**:
  1. 계좌 셀렉터 드롭다운 확인
- **기대 결과**:
  - 드롭다운 기본값이 "전체 계좌"로 표시됨
  - "계좌 상세 보기" 링크가 표시되지 않음

#### 1-3. 계좌 셀렉터 — 특정 계좌 선택 시 데이터 필터링
- **전제조건**: 로그인된 상태, 계좌가 1개 이상 존재, /stocks 접근
- **단계**:
  1. 계좌 셀렉터를 열어 특정 계좌 선택
- **기대 결과**:
  - 드롭다운이 선택한 계좌명으로 변경됨
  - "계좌 상세 보기" 링크가 표시됨
  - 해당 링크가 `/stocks/accounts/{accountId}` URL을 가짐

#### 1-4. 보유 종목 테이블 — 손익 색상 표시
- **전제조건**: 로그인된 상태, 보유 종목이 1개 이상 존재, /stocks 접근
- **단계**:
  1. 보유 종목 테이블 로드 확인
  2. 미실현 손익 셀의 색상 클래스 확인
- **기대 결과**:
  - 양수 손익 행은 `text-gain` 클래스를 가짐
  - 음수 손익 행은 `text-loss` 클래스를 가짐
  - 종목명이 `/stocks/{stockId}` 링크를 가짐

#### 1-5. 계좌 추가 다이얼로그 — 오픈 및 취소
- **전제조건**: 로그인된 상태, /stocks 접근
- **단계**:
  1. "계좌 추가" 버튼 클릭
  2. 다이얼로그 렌더링 확인
  3. "취소" 버튼 클릭
- **기대 결과**:
  - "계좌 추가" 다이얼로그가 열림
  - 계좌 유형 셀렉터, 증권사 셀렉터, 계좌 별칭 입력 필드가 표시됨
  - "취소" 클릭 후 다이얼로그가 닫힘

#### 1-6. 계좌 추가 다이얼로그 — 증권사 미선택 시 유효성 오류
- **전제조건**: 로그인된 상태, 계좌 추가 다이얼로그가 열린 상태
- **단계**:
  1. 증권사를 선택하지 않고 "추가" 버튼 클릭
- **기대 결과**:
  - "증권사를 선택해주세요." 오류 메시지가 `text-destructive` 요소로 표시됨
  - 다이얼로그가 닫히지 않음

### 2. /stocks/trades — 매매 내역 (순차 실행)

#### 2-1. 매매 추가 — BUY 거래 정상 등록
- **전제조건**: 로그인된 상태, 종목과 계좌가 1개 이상 존재, /stocks/trades 접근
- **단계**:
  1. "매매 추가" 버튼 클릭
  2. 종목 검색 후 종목 선택
  3. 계좌 선택
  4. 유형 "매수" 선택
  5. 거래일, 단가(10000), 수량(10) 입력
  6. "추가" 버튼 클릭
- **기대 결과**:
  - 다이얼로그가 닫힘
  - 매매 목록에 새 행이 추가되어 해당 종목명과 "매수" 배지가 표시됨
  - 총금액 미리보기(단가 × 수량)가 입력 중 폼 내에서 표시됨

#### 2-2. 매매 추가 — 종목 미선택 시 유효성 오류
- **전제조건**: 로그인된 상태, /stocks/trades 접근, 매매 추가 다이얼로그 열린 상태
- **단계**:
  1. 종목 선택 없이 계좌, 단가, 수량만 입력하고 "추가" 클릭
- **기대 결과**:
  - "종목을 선택해주세요." 오류 메시지가 표시됨
  - 다이얼로그가 닫히지 않음

#### 2-3. 매매 수정 — 단가 및 수량 변경
- **전제조건**: 2-1에서 등록된 거래가 목록에 존재
- **단계**:
  1. 해당 거래 행의 편집(연필) 아이콘 클릭
  2. 단가를 12000으로 변경
  3. 수량을 5로 변경
  4. "수정" 버튼 클릭
- **기대 결과**:
  - 다이얼로그 제목이 "매매 수정"으로 표시됨
  - 수정 후 해당 행의 단가, 수량, 총금액이 갱신됨
  - 종목/계좌/유형 셀렉터는 수정 폼에서 표시되지 않음 (read-only)

#### 2-4. 매매 삭제 — 확인 후 제거
- **전제조건**: 매매 목록에 1건 이상 존재
- **단계**:
  1. 삭제(휴지통) 아이콘 클릭
  2. 브라우저 confirm 다이얼로그에서 확인
- **기대 결과**:
  - 해당 거래 행이 목록에서 사라짐

#### 2-5. 필터 — 매매 유형(SELL) 필터링
- **전제조건**: 로그인된 상태, BUY/SELL 거래가 모두 존재, /stocks/trades 접근
- **단계**:
  1. "유형" 셀렉터에서 "매도" 선택
- **기대 결과**:
  - 목록에 "매도" 배지 행만 표시됨
  - "매수" 배지 행이 표시되지 않음

#### 2-6. 필터 초기화
- **전제조건**: 2-5에서 필터가 적용된 상태
- **단계**:
  1. "초기화" 버튼 클릭
- **기대 결과**:
  - 유형 셀렉터가 "전체"로 초기화됨
  - 전체 거래 목록이 다시 표시됨

### 3. /stocks/[stockId] — 종목 상세

#### 3-1. 종목 정보 헤더 렌더링
- **전제조건**: 로그인된 상태, 유효한 stockId로 /stocks/{stockId} 접근
- **단계**:
  1. 페이지 로드
  2. 종목 정보 카드 확인
- **기대 결과**:
  - 종목명이 텍스트로 표시됨
  - 종목 코드 배지(Badge variant="outline")가 표시됨
  - 마켓 배지(Badge variant="secondary")가 표시됨 (market 값이 있는 경우)
  - 보유 중인 경우 현재가와 수익률(%)이 우측에 표시됨

#### 3-2. 보유 현황 섹션 — 보유 종목이 있을 때 표시
- **전제조건**: 로그인된 상태, 해당 종목의 보유 수량이 0보다 큰 상태
- **단계**:
  1. /stocks/{stockId} 접근
  2. "보유 현황" 카드 확인
- **기대 결과**:
  - "보유 현황" 카드가 표시됨
  - HoldingsTable에 해당 종목의 수량, 평균단가, 현재가, 평가금액, 손익, 비중 열이 표시됨

#### 3-3. 해당 종목 매매 내역만 표시
- **전제조건**: 로그인된 상태, 해당 종목의 매매 내역이 1건 이상 존재
- **단계**:
  1. /stocks/{stockId} 접근
  2. "매매 내역" 카드 확인
- **기대 결과**:
  - 매매 내역 카드에 (N건) 건수가 표시됨
  - 테이블의 모든 행이 해당 종목명을 포함함

#### 3-4. 뒤로가기 링크
- **전제조건**: 로그인된 상태, /stocks/{stockId} 접근
- **단계**:
  1. 좌측 상단 ArrowLeft 버튼 클릭
- **기대 결과**:
  - /stocks 페이지로 이동함

---

### 4. /stocks/accounts/[accountId] — 계좌 상세

#### 4-1. 계좌 정보 카드 렌더링
- **전제조건**: 로그인된 상태, 유효한 accountId로 /stocks/accounts/{accountId} 접근
- **단계**:
  1. 페이지 로드
  2. 계좌 정보 카드 확인
- **기대 결과**:
  - 계좌 별칭 또는 증권사명이 제목으로 표시됨
  - 계좌 유형 배지(Badge variant="outline")와 증권사 배지(Badge variant="secondary")가 표시됨
  - 평가금액과 미실현 손익이 우측에 표시됨

#### 4-2. 해당 계좌 보유 종목 테이블
- **전제조건**: 로그인된 상태, 해당 계좌에 보유 종목이 1개 이상 존재
- **단계**:
  1. /stocks/accounts/{accountId} 접근
  2. "보유 종목" 카드 확인
- **기대 결과**:
  - (N종목) 건수가 표시됨
  - 종목명 링크가 `/stocks/{stockId}` URL을 가짐

#### 4-3. 월별 실현 손익 차트 — 연도 네비게이션
- **전제조건**: 로그인된 상태, 해당 계좌에 실현 손익 데이터가 존재
- **단계**:
  1. /stocks/accounts/{accountId} 접근
  2. "월별 실현 손익" 카드의 연도 표시 확인
  3. 이전 연도 버튼(‹) 클릭
  4. 다음 연도 버튼(›) 클릭
- **기대 결과**:
  - 기본 연도가 현재 연도로 표시됨
  - 이전 버튼 클릭 후 연도가 1 감소함
  - 다음 버튼 클릭 후 연도가 현재 연도를 초과하지 않음 (disabled 상태)
  - 5년 이전으로 이전 버튼이 disabled됨

#### 4-4. 월별 실현 손익 차트 — 데이터 없을 때 빈 상태
- **전제조건**: 로그인된 상태, 해당 계좌의 선택 연도에 실현 손익 데이터가 없음
- **단계**:
  1. /stocks/accounts/{accountId} 접근
  2. 데이터가 없는 연도로 이동
- **기대 결과**:
  - "표시할 성과 데이터가 없습니다." 텍스트가 표시됨
  - Recharts BarChart가 렌더링되지 않음
